# RobloxFix — SEO landing page

Готовый статический сайт для услуги по диагностике/настройке отображения изображений в Roblox.

## Перед публикацией
1. В `index.html` замени `YOUR_AVITO_LINK` и `YOUR_FUNPAY_LINK` на реальные ссылки.
2. Замени `https://YOUR-DOMAIN.example/` в `index.html`, `robots.txt` и `sitemap.xml` на настоящий адрес сайта.
3. Проверь текст и цены.
4. Для публикации без отдельного хостинга можно использовать GitHub Pages.

## Важно
Сайт не обещает гарантированный результат и не просит пароль от Roblox. Не размещай на сайте пароли, cookies, токены или другие секреты.
